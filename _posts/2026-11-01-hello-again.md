The blog is back. The first version was a little PHP app I wrote in 2017 on Slim and Twig
([still on GitHub](https://github.com/nekocentral/Neko_Blog_Sytem) for nostalgia's sake).
This one is plain Markdown files built by Jekyll and hosted on GitHub Pages: no server to patch.

## Writing a post

Add a file to `_posts/` named `YYYY-MM-DD-title.md`, start it with:

```yaml
---
title: My post title
tags: [homelab]
---
```

…write Markdown below it, commit, push. Done.
